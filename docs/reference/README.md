# Offline reference renders

Generated by:

```sh
swift run AutoTechnoReference
```

All files are 16-bit PCM stereo at 44.1 kHz.

- `mvp_seed{seed}_{polished|sketch}.wav` — one-bar MVP reference.
- `v2_seed{seed}_{polished|sketch}_32bars.wav` — full 32-bar procedural v2 reference.
- `v2_*_matched_to_mvp.wav` — v2 reference gain-matched to the corresponding MVP RMS.
- `v3_seed{seed}_persistent_32bars.wav` — experimental Persistent v3 fixed-seed renders.
- `v3_seed{seed}_persistent_32bars_matched_to_v2.wav` — v3 renders gain-matched to the corresponding approved v2 Club Punch RMS.
- `jukebox_seed48291_cycle0_4scenes.wav` — four consecutive Continuous v2 scenes.
- `jukebox_seed48291_cycle0_8scenes.wav` — eight consecutive Continuous v2 scenes (256 bars).
- `v2_translation_report.json` — fixed-seed/treatment/mastering objective checks.
- `v3_translation_report.json` — Persistent v3 fixed-seed objective checks.
- `jukebox_long_play_translation_report.json` — eight-scene long-play objective checks.
- `jukebox_translation_report.json` — long-play scene count, continuity, and safety checks.
- `v2_manifest.json` — v2 peak, true peak, RMS, stereo, low-stereo, hash, and offline musical-quality metrics for every fixed-seed render.

The fixed comparison seeds are `42`, `48291`, and `90909`. Do not replace
these files after a DSP change without also updating the metrics and recording
the reason in [MVP_REFERENCE.md](../MVP_REFERENCE.md) or the v2 listening gate.
