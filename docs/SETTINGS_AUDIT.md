# Settings audit

This audit records the listener promise, current implementation, overlap, and
the target audible consequence for the semantic settings. Values remain
deterministic scene intentions; the primary UI exposes only the strongest
destinations.

| Setting | Listener promise | Current effect | Assessment / wow target |
| --- | --- | --- | --- |
| Groove | Forward, physical pulse | Swing and event density | Strong; keep under Drive |
| Syncopation | Rhythmic push away from the grid | Weak bass candidates and drive | Advanced; high values should create a clear fill |
| Beat shape | Straight to broken rhythm | Selects kick/clap vocabularies | Strong structural effect; advanced until surfaced as a named rhythm mode |
| Polyrhythm | Competing rhythmic cycle | Adds deterministic triplet bass candidates | Too subtle; advanced and needs audible 3:2 evidence |
| Darkness / Shadow | Tonal weight and low-end shadow | Bass register, timbre, filters, mix tilt | Keep and rename Shadow |
| Atmosphere / Space | Room around the groove | Delay/reverb, send, stereo spread | Keep as primary Space; strengthened in renderer |
| Atmospheric darkness / Fog | Veiled, obscured space | Reverb filtering and air loss | Keep separate from Shadow; rename Fog |
| Hypnosis | Repetition and locked attention | Motif persistence, bass decay, swing | Keep; high values need sustained motif identity |
| Aggression / Impact | Harder transient and edge | Kick attack, saturation, limiting ceiling | Keep as primary Impact; strengthen within safety limits |
| Melodicity | More melodic vocabulary | Scale-degree blend | Advanced; currently too small for a primary control |
| Synth presence | More audible synth voice | Motif level and waveform brightness | Advanced; overlaps Musicality |
| Note activity | More motif movement | Chance of an additional motif note | Advanced; needs phrase-level development |
| Overall chaos | Global unpredictability | Amplifies per-voice chaos | Advanced coordinator for bounded mutations |
| Drum chaos | Drum variation | Quiet deterministic ghost hits | Advanced; high-end mutation strengthened |
| Synth chaos | Synth instability | Frequency jitter | Advanced; currently too subtle |
| Texture chaos | Surface motion | Noise/reverb modulation | Advanced; currently too subtle |
| Pace of change | How quickly the machine evolves | Phrase lengths and derived tempo | Keep advanced; distinct from immediate controls |
